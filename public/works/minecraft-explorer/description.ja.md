# Minecraft Explorer

複数のランチャーや Mod パックに分散した Minecraft Java のワールド、リソースパック、Mod、シェーダー、データパックをまとめて管理する Windows アプリです。コンテンツの検索、所属ディレクトリの確認、容量分析、確認付きのバックアップとファイル操作に対応します。

## ダウンロードと起動

上部のダウンロードボタンから **MinecraftExplorer-1.0-win-x64.exe** を取得し、そのまま起動します。インストールや解凍は不要です。読み取り可能な任意のフォルダーに置けます。更新前に旧版を終了してください。

対象は Windows 10/11 x64 です。このツール自体に Rust や Java、外部アイコンは不要ですが、Microsoft Visual C++ x64 ランタイムが必要です。`VCRUNTIME140.dll` がない場合は [Microsoft 公式ランタイム](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) を導入してください。クリーンな Windows 仮想環境での検証は未実施です。HMCL の JAR には別途 Java が必要です。

## 最初の使い方

1. **設定**で `versions` を含む Minecraft ルートを追加します。例：`D:\PCL2\MinecraftPcl`。`versions` だけを選択しないでください。カスタムゲームディレクトリは所属ルートを指定して追加できます。
2. 追加後は **容量分析**へ移動し、インデックスを更新してから新しいディレクトリを自動分析します。キャンセルすると登録と既に読み取った結果は残り、後続の自動分析を停止します。
3. ワールドやパックを名前、インスタンス、パスで検索し、ゲームディレクトリで絞り込みます。選択すると詳細を表示し、ダブルクリックまたは Enter でエクスプローラーに位置を表示します。
4. お気に入りとタグで整理できます。**F5** で更新します。変更監視は初期状態で有効で、設定から無効にできます。
5. アプリの言語は **中国語 / English**、テーマは **ダーク / ライト** に対応し、変更は即時反映・保存されます。アプリ本体に日本語 UI はありません。

## 容量分析とバックアップ

ツリーマップの面積は論理ファイルサイズを表します。フォルダーをダブルクリックして掘り下げ、「上の階層」で戻ります。重複する登録元は一度だけ数え、読み取れない項目がある場合は下限値を表示します。論理サイズはディスクの割り当て容量とは異なります。ファイル変更後は再分析してください。

名前変更、コピー、移動、バックアップ、ごみ箱への移動は、プレビューでパスを確認してから実行します。コピーと移動は内容を検証し、同名ファイルを上書きしません。永久削除への切り替えはありません。バックアップ先は登録ゲームディレクトリの外に置き、復元時も検証します。Minecraft を終了してから操作してください。起動中ワールドのホットバックアップには対応しません。

スキャンや監視で問題が発生した場合、下部の「View issues」から対象パスと原因を確認できます。同じメッセージはまとめられ、今回の起動中の最新 100 件だけを保持します。「Clear」は表示だけを消し、ファイルは変更しません。ファイル操作のエラーは操作画面に、復元に必要な記録はバックアップ画面に残ります。

## ランチャー

**PCL2、PCL CE、HMCL** を登録し、コンテンツに対象バージョンを関連付けられます。ランチャーを開く操作の後は、元のランチャーでバージョンを選んで起動します。

このアプリから特定バージョンのスクリプトを実行する場合、元ランチャーで出力した **BAT / CMD** と作業ディレクトリを関連付けます。直接起動には対象バージョンのスクリプトが必要です。ランチャーを開いた場合は、その画面でバージョンを選択します。スクリプトにはログイン情報が含まれる場合があるため、公開しないでください。

PCL2 / PCL CE は既存スクリプトを自動認識できます。元ランチャーで対象バージョンを一度起動してから関連付け画面を開きます。バージョンとゲームディレクトリが両方一致した場合だけ自動入力し、アプリデータの launch-scripts に独立したコピーを保存します。他バージョンの起動でこの関連付けは上書きされません。確認して保存してください。Auto-detect で再確認できます。不一致や未対応の形式は手動で指定します。コピーに元のログイン情報が含まれる場合があるため、公開しないでください。認証切れの場合は元ランチャーで再起動してから再認識します。

## データとライセンス

設定、インデックス、お気に入り、タグは標準で `%LOCALAPPDATA%\MinecraftExplorer\` に保存されます。スキャンや容量分析ではゲーム内容を変更・送信しません。ファイル操作はプレビューと確認が必要です。登録元の削除はアプリ内の関連付けのみを削除します。

独自ソースは MIT ライセンスです。第三者ライセンス原文と Slint 表示を EXE に内蔵し、**設定 → About → Export third-party licenses** でアプリのデータディレクトリに出力できます。
