## 设计与兼容

沿用现有 React、Lucide、Geist、青色焦点、语义深浅色和小圆角；官网维持原阅读布局，后台使用紧凑的文件夹／文件树。既有导航名称、文档 slug、正文、图片路径、作品和网站内容不因本次界面调整而改变。分类仍为单层，文章可放在分类内或与分类同级。

根级文档使用显式 `categoryId: ""`，没有生成“未分类”占位分类；没有任何分类的空文档库也可以新建并公开根级文章。其他分类 ID 必须指向真实分类，缺失、null、空白和未知 ID 继续拒绝。沿用 schemaVersion 1，原 23 篇规则不需要迁移或重新发布。

## 操作方式

- 官网分类左侧箭头展开／收起文章，名称仍可进入分类目录。收起不会切换或关闭当前正文；直达文章时展示其所在分类，搜索时可找到匹配文章。浏览器可记录折叠偏好，不可用时仍能正常导航。
- Admin 左侧“文档根目录”旁的新文件／文件夹图标启动就地输入；分类行的操作菜单可以在该分类中新建文章。Enter 确认名称，Esc 取消，失焦不自动创建。新内容先留在当前编辑草稿，不立即写服务器。
- 文章和分类可通过行旁菜单、右键菜单或树内 F2 重命名。已有 slug 保持固定；文章名按当前编辑语言修改。分类的其他字段仍可在“分类设置”中维护。
- 文章可拖入分类或根目录，也可使用右侧“所属分类”选择器和“移到根目录”菜单；移动保持文章编号、slug、图片归属与公开地址。
- 树内 Delete 和删除菜单会先确认。删除文章使用可恢复归档，保存及确认发布后才从官网下架；历史文件保留。非空分类先移动文章或合并，避免误删整组内容。

保存和公开仍然独立：完成整理后保存文档草稿，再预览发布差异并确认发布。展开／折叠属于本机导航偏好，不会产生待保存内容，不进入发布差异。
