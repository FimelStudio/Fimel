# Bingo But Don't Do It

A competitive Minecraft mod that combines Bingo with the “Don't Do It” challenge. Complete objectives while avoiding your team's forbidden actions.

## Match systems

- Shared team lives.
- Opposing objectives and special events.
- Optional voice-keyword play.

## Requirements

The published build targets **Minecraft Java 1.21.11 / Fabric**. Check the Versions tab for Fabric Loader, Fabric API and optional dependencies before installing.

Voice-keyword play requires Simple Voice Chat.

## Downloads and feedback

The download button finds the latest official GitHub release. If the request fails, it downloads the locally hosted 1.21.11 v1.0 JAR.
