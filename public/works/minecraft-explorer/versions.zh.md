点击上方下载按钮只下载这个 EXE，不是安装器或 ZIP。首次运行会在 `%LOCALAPPDATA%\MinecraftExplorer\` 创建缓存与配置；不会在游戏目录生成扫描文件。无需 Java 来运行本工具，HMCL JAR 自身需要 Java。

暂时建议同一缓存只运行一个程序窗口。更详细的兼容与操作边界见 [README](https://github.com/Ylong4004/Minecraft-Explorer/blob/main/README.md)。
