## インストール

一覧から必要な版の ZIP をダウンロードして展開し、Blockbench Desktop のローカルプラグイン機能で `minecraft_obj_cubizer.js` を読み込みます。旧版を無効にしてから、新版のインストールまたは再読み込みを行ってください。

操作は上部の **Minecraft Cubizer** メニューから行います。当サイトの v1.6.1 は Blockbench Desktop 5.2.0 以上と表記し、5.2.2 を推奨します。構造のバックグラウンド解析には Worker と DecompressionStream が必要です。

各ファイルとチェックサムはバージョン一覧に表示されます。[旧版 1.4.0](https://download.studiofimel.com/works/tools/minecraft-obj-cubizer/1.4.0/minecraft_obj_cubizer-1.4.0.zip) も保持しており、Blockbench Desktop 4.8.0 以上に対応します。選んだ版の動作環境を確認してください。
