# 官网下载区与 Admin 完善计划

日期：2026-10-16。基线：`53f9005`；本地标签 `baseline/admin-publishing-20261016`；开发分支 `feat/admin-publishing-downloads`。

本轮开发及合并、推送、生产发布与聚合计数采集均已获用户明确确认。作品和网站文案仍需管理员在后台正常预览、确认发布，本次部署不代为发布内容。两份用户原始任务文档保持未跟踪，不覆盖或提交。

## 已确认范围

- 官网仅完善下载区：版本、游戏兼容版本、加载器、平台、文件大小、历史版本与多文件下载。继续兼容原有主下载和三个发行文件地址。
- 后台全部六项：发布状态与时间、可视化发布预览与差异、编辑恢复和更新提示、按作品保存与冲突处理、现有官网内容管理、图片用途和按作品统计。
- 保留当前风格、三语、GitHub Pages、R2、Access 和历史数据。官网筛选、SEO、首屏重设计不在本轮范围。
- 用户已明确允许后台管理近期更新并新增官网展示区；同时接入现有精选与工作室区块，保持视觉风格。

## 开发顺序和验收

1. 下载模型及兼容校验、官网版本与多文件界面；验证旧目录和不完整元数据仍可正常下载。
2. 按作品条件保存、不同作品并发合并、同作品三方差异；保留旧全库 API 和 ETag 保护，验证并发不丢修改。
3. 发布指纹和时间、真实样式预览、字段与正文差异；不自动重发历史作品，没有旧基线时明确提示。
4. 按身份隔离的本机恢复、成功保存清理、恢复前核对远端；版本变化只提示，不强制刷新或丢弃编辑。
5. 网站内容私有草稿、可视化编辑及独立发布；原页面默认内容和公开目录兼容。
6. 图片引用定位与安全移除、按作品汇总访问和下载口径；不自动删除文件，不伪造完整下载人数。
7. 运行相关单元、真实本地 R2 runtime、浏览器与构建检查；整理交付和精确发布范围后集中确认。
