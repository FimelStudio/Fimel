# 导航品牌标识优化

日期：2026-10-14。按保留式优化处理，只修改导航品牌组合及其资源，不重做页面、品牌图形或菜单。

## 原因与处理

原 PNG 为 824×825 像素，导航将它放在约 104×44 的横向框内，圆形图形实际只有约 40-44px。小字号与细线被大幅缩小，加上悬停缩放会使用非整数尺寸，使品牌辨识度不足。增加图片像素或锐化不能替代合适的展示尺寸。

- 从原图轮廓描摹生成 `public/assets/brand/fimel-logo.svg`，保留黑／灰图形结构，不加入新图案；导航采用透明矢量版，不嵌入 PNG。原 PNG 字节保持不变，继续用于备用标识、favicon 与分享预览。
- 标志显示尺寸为手机 44px、平板 52px、桌面 56px。右侧增加固定字标 `Fimel Studio`，采用 Minecraft 风格的 Monocraft 像素字体，仅用于字标及备用单字母图形。
- SVG 为 5,751 字节，字体子集为 2,692 字节。字体保留可打印 ASCII，使用本地 WOFF、`font-display: swap` 及预加载；来源、版权与 OFL 许可证随文件保留，不依赖外部字体服务。
- 字标预留固定宽度，减少字体切换影响。品牌悬停改为轻微透明度反馈，不将标志与像素文字缩放到非整数尺寸。
- 桌面左右列对称，使三个导航项保持居中；768px 下适当收紧菜单间距，避免日文长标签与字标重叠。手机仍直接显示三个导航项。
- SVG 请求失败时回退到原 PNG；两张图片均失败时保留单字母图形与完整文字。字体加载失败仍可访问品牌链接，不会阻塞页面。
