## 1.6.1 / 建築読み込みとビューポートの負荷改善

パッケージ内の記録：2026-10-14 / Ylong。当サイトでの公開日：2026-10-16。

- 読み込み中は新しい cube の描画を遅延させ、完了またはキャンセル後に標準描画へ戻します。
- テクスチャ読み込み前に画像寸法を設定し、モデル全体の形状と UV を繰り返し更新する処理を減らしました。
- 建築パフォーマンスモードを初期状態で有効化。親グループとマテリアルごとに未選択の対応 cube をまとめ、元のモデルデータと標準の選択操作を保持します。
- 大量選択時の UV オーバーレイ数を制限し、モード無効化やプロジェクト切り替えで元の動作へ戻します。
- アニメーション、半透明、特殊描画のテクスチャを対象外にし、有効な Multi Cube Mesh Optimizer との重複処理を避けます。

パッケージには Blockbench 5.2.2 での速度、画像比較、選択、編集、取り消し、保存の実機確認が記録されています。ゲーム内での書き出しや再生を確認した記録ではありません。

## 1.6.0 / バックグラウンド処理、選択範囲プレビューと部品

2026-10-13 / Ylong。

- NBT の展開、解析、選択範囲の走査を中止可能な Worker へ移動し、無関係なエンティティ情報や範囲外のブロックを読み飛ばします。
- 状態・モデル・ID フィルターをキャッシュし、Blockbench 5.2.2 の制限されたファイル API では JAR の非同期読み込みとキャッシュを使います。ZIP64 にも対応します。
- 最大 2,048 インスタンスの簡易プレビューを追加。範囲を確認してから編集可能な cube を生成します。
- プレビューでアニメーション部品の範囲と軸心を設定できます。Animated Java の自動グループ化では静的な本体と指定した可動部品を分け、結合もその境界を保持します。
- 対応するハーフブロック、一部の階段、複数 cube の形状を連続軸に沿って結合し、対応する直角回転と外形を保持します。
- 面の UV ピクセルを切り抜いて並べ、非正方形テクスチャや縦のアニメーションに対応。PNG 書き出し時にフレーム情報を `.mcmeta` へ保存します。
- 半透明の結合は別設定で初期状態では無効。終了、キャンセル、アンロードでプレビューと Worker の資源を解放します。

## 1.5.0 / 新版への対応と大規模建築の読み込み

2026-10-13 / Ylong。

- Blockbench 5.2.2 のテクスチャ参照と既存 Animated Java Blueprint に対応し、テクスチャ寸法、UV モード、アニメーションを保持します。
- 座標範囲、ブロック ID のワイルドカード、グループ化とスケールの設定を追加しました。
- 任意のブロック結合、タイルテクスチャ、隠れた面の除去、進捗付きの分割生成とキャンセル時のロールバックに対応します。
- 対応する貼り付け元のテクスチャを再利用し、元ブロックの処理制限と生成 cube 数の制限を分離しました。
- classic schematic のメタデータと AddBlocks、Sponge schematic v3、litematic のビット配置と負の寸法、DataVersion に応じた MCA の復号を修正しました。
