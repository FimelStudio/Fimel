# 更新履歴

## 1.0.2 · 2026-10-13

- 設定画面の古い開発段階の説明と常時表示のログを削除し、重複するフッターを整理。
- スキャンの問題を必要なときだけ下部から確認でき、言語切り替え・重複の統合・表示の消去に対応。
- ランチャーの状態表示を分かりやすくし、起動スクリプトの関連付けを正しく表示。

## 1.0.1 · 2026-10-12

- PCL2 / PCL CE の関連付け画面で対象スクリプトを自動認識。
- バージョンとディレクトリの一致を確認し、独立コピーで後の上書きを防止。
- Auto-detect の再確認と未検出時の案内を追加し、手動入力を維持。

## 1.0.0 · 2026-10-12

- 複数登録元の検索、所属情報、アイコン、お気に入り、タグ。
- 容量ツリーマップ、分類表示、階層移動、新規ディレクトリの自動分析。
- 確認付きの名前変更、検証付きコピー・移動、バックアップ・復元、ごみ箱への移動。
- PCL2、PCL CE、HMCL の起動とバージョン別スクリプトの関連付け。
- 中国語 / 英語 UI とダーク / ライトテーマの即時反映と保存。
