# Minecraft OBJ キューブ変換ツール

Minecraft 建築の OBJ や構造ファイルを Blockbench に読み込み、選択・編集・書き出し可能なキューブモデルに変換します。Java 版リソースパックのモデル制作に加え、既存の Animated Java Blueprint プロジェクトへの読み込みにも対応します。

## 対応する入力

- **建築 OBJ**：`.obj`、`.mtl`、PNG テクスチャを読み込み、軸に沿ったキューブを再構築します。Minecraft 風の建築向けで、一般的な三角形メッシュや曲面の変換用ではありません。
- **構造ファイル**：`.schematic`、`.schem`、`.litematic`、構造 `.nbt`、単一 `.mca` リージョンに対応します。
- **モデルとテクスチャ**：リソースパックのフォルダーや Minecraft JAR/ZIP から blockstate/model JSON と特殊ブロックの形状を読み込み、未指定の UV を面の寸法から計算します。

## v1.6 系列の作業手順

1. パッケージを展開し、Blockbench Desktop のローカルプラグイン機能で `minecraft_obj_cubizer.js` をインストールします。5.2.2 を推奨し、当サイトの v1.6.1 は 5.2.0 以上と表記しています。
2. **Minecraft Cubizer** メニューから OBJ を読み込むか、Minecraft 構造を先にプレビューします。
3. テクスチャの参照元、X/Y/Z の範囲、ブロック ID を指定します。範囲は両端を含み、移動や中央配置の前に適用されます。ID では `*` が使えます。
4. 簡易プレビューで選択範囲を確認してから、編集可能な cube を生成します。バックグラウンド処理を中止でき、分割生成では進捗表示とキャンセル時のロールバックを利用できます。
5. テクスチャ、特殊ブロック、通常の立方体へ置き換えられた項目を確認し、必要なテクスチャをリソースパックへ書き出します。

## 大規模建築とアニメーション

v1.6.1 の**建築パフォーマンスモード**は初期状態で有効です。対応する未選択 cube をまとめて描画し、元のモデル、UV、選択・編集データは保持します。選択中の cube、ペイント／アニメーションモード、非対応テクスチャでは標準描画を使います。モードは無効化できます。読み込み中の新しい cube の描画も遅延させ、テクスチャごとの建築全体の再描画を減らします。

Animated Java Blueprint では既存のテクスチャ寸法、UV モード、アニメーションを保持します。ブロック単位、空間分割、単一グループ、アニメーション部品で整理でき、Animated Java の自動モードでは静的な本体と指定した可動部品に分けます。プレビューから部品の範囲や軸心を設定でき、結合は部品の境界を越えません。

ブロック結合、半透明結合、隠れた面の除去は任意で、初期状態では無効です。個別編集やアニメーション用の分割が必要なら無効のまま使ってください。生成されたタイルテクスチャは面の UV 密度を保持し、縦方向のアニメーションにも対応します。PNG と対応する `.mcmeta` をモデルと一緒に書き出してください。

## 制限

- チェスト内のアイテム、看板の文字、旗の模様、プレイヤーヘッドの所有者などのブロックエンティティ情報は読み込みません。
- 初期上限は元ブロック数ではなく **生成後の 5,000 cube** です。元ブロックの処理上限は別設定です。プレビューは最大 2,048 個の簡易インスタンスで、完全なモデルや実テクスチャ表示ではありません。
- Java Block/Item の一般的な座標範囲は `-16` から `32` です。1 ブロックを 1 単位にすれば約 48 ブロック、16 単位なら約 3 ブロックの幅になります。
- Minecraft JAR/ZIP のバニラ PNG はプレビュー専用で、モデル保存時に自動保存されません。生成された独自テクスチャは明示的に書き出します。
- バックグラウンド解析には Worker と DecompressionStream が必要です。最終生成や編集にはメインスレッドと GPU メモリーも使うため、大規模な建築は範囲を絞るか分割してください。

パッケージの説明には Blockbench 5.2.2 と Animated Java 1.11.0 での実機確認が記録されています。ゲーム内への書き出しとアニメーション再生は未検証です。各ファイルと動作環境、更新内容は「バージョン」で確認できます。
