## Installation

Download the required ZIP from the version list, extract it and load `minecraft_obj_cubizer.js` through Blockbench Desktop's local plugin installer. Disable an older installation before installing or reloading the replacement.

Open the **Minecraft Cubizer** menu in the top menu bar. This site's v1.6.1 release lists Blockbench Desktop 5.2.0 or newer; 5.2.2 is recommended. Background structure parsing requires Worker and DecompressionStream.

Files and checksums are shown in the version list. The original [1.4.0 archive](https://download.studiofimel.com/works/tools/minecraft-obj-cubizer/1.4.0/minecraft_obj_cubizer-1.4.0.zip) remains available and requires Blockbench Desktop 4.8.0 or newer. Check the requirements for the version you choose.
