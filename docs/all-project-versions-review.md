## 核对与计划

用户要求所有作品沿用上一轮的版本列表形式。只读核对线上 28 个作品：转换器已有结构化发行记录，其余包括 2 个旧下载记录作品、20 个平台分发作品、5 个未提供公开下载的作品。原通用组件在没有结构化发行记录时直接返回旧 Markdown，造成其他作品没有使用列表。

本轮是保留品牌的资源详情页修复，沿用既有黑曜石／浅色背景、青色、Geist、Lucide 和小圆角。设计差异 3、动效 1、密度 6。保留导航、路由、顶部下载操作与所有正文、日期、文件和外部分发地址。

1. 无结构化发行记录时，以已有作品字段显示统一版本行；既有下载显示文件名、版本、大小和记录更新时间，平台作品显示平台入口。
2. 未标注版本号时明确提示；日期标为“记录更新于”，不假定为版本发行日；未知 SHA-256 不显示。未发行作品使用统一空状态。
3. 官网、后台正文、发布预览与旧作品的发行版本编辑页复用组件。后台预览禁止下载及跳转；管理员可通过完整字段维护原入口，也可新增结构化发行版本。
4. 检查全部 28 个本地作品、三语、深浅色和手机布局，以及后台三类旧作品与已有多版本场景。

## 发布范围

本轮仅修改通用展示代码和操作提示，不批量保存、发布或覆盖作品数据，不需要迁移文件，也不更改作品更新时间。当前已完成本地修复，尚未部署；待用户确认后合并、推送并发布官网和 Admin。
