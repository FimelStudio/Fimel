# Bingo But Don't Do It

Bingo と「やってはいけないチャレンジ」を組み合わせた Minecraft MOD です。自分のチームの禁止行動を避けながら、目標を達成していきます。

## 対戦の仕組み

- チームでライフを共有。
- 対抗目標と特殊イベント。
- 任意で有効化できる音声キーワードルール。

## 動作環境

公開版は **Minecraft Java 1.21.11 / Fabric** 向けです。「バージョン」タブで Fabric Loader、Fabric API と追加依存 MOD を確認してから導入してください。

音声キーワード機能には Simple Voice Chat が必要です。
