# Minecraft OBJ 方块转换器

把 Minecraft 建筑 OBJ 或结构文件导入 Blockbench，转换为可继续选择、编辑和导出的方块模型。适用于 Minecraft Java 资源包建模，也支持在已有 Animated Java Blueprint 项目中继续制作。

## 导入什么

- **OBJ 建筑**：读取 `.obj`、`.mtl` 和 PNG 贴图，重建轴对齐方块。适合 Minecraft 风格建筑，不是通用三角网格或曲面转换器。
- **结构文件**：支持 `.schematic`、`.schem`、`.litematic`、结构 `.nbt` 与单个 `.mca` 区域文件。
- **模型与贴图**：可指定资源包文件夹或 Minecraft JAR/ZIP，读取 blockstate/model JSON、特殊方块外形与贴图；缺省 UV 按实际面像素尺寸计算。

## v1.6 系列的新工作流程

1. 在 Blockbench 桌面版通过本地插件入口安装解压后的 `minecraft_obj_cubizer.js`。新版本建议使用 5.2.2；本站 v1.6.1 发行记录标注为 5.2.0 以上。
2. 打开顶栏 **Minecraft Cubizer / Minecraft 方块转换器** 菜单，选择 OBJ 导入，或先预览 Minecraft 结构。
3. 选择贴图来源，按 X/Y/Z 范围和方块 ID 筛选。ID 支持 `*` 通配符；范围包含两端坐标，在居中或移动前应用。
4. 用低细节预览检查选区，确认后再创建可编辑 cube。后台处理支持取消；创建过程分批显示进度，可取消并回滚本次导入。
5. 检查特殊方块、贴图和退回完整方块的提示。需要时，将 OBJ、结构和平铺贴图按资源路径导出到资源包目录。

## 大建筑与动画制作

v1.6.1 的**建筑性能模式**默认开启，批量绘制未选中的兼容 cube，保留原始模型、UV、选择和编辑数据。选中方块、绘画／动画模式及不适合代理的贴图使用原生渲染；可以随时关闭。导入期间暂缓新 cube 绘制，避免逐张加载贴图和收尾时反复刷新整座建筑。

Animated Java Blueprint 导入保留已有贴图尺寸、UV 模式与动画。支持逐方块、空间分块、单组及动画部件分组；Animated Java 自动模式使用静态主体与指定运动部件。预览中可以定义部件范围和轴心，合并不会跨越部件边界。

方块合并、透明合并和隐藏面剔除均为可选项，默认关闭。需要逐块编辑或拆分动画时建议保持关闭。合并贴图会按面 UV 裁剪并平铺，支持竖向动画条；生成的 PNG 及对应 `.mcmeta` 需要随模型导出。

## 使用边界

- 直接结构导入不读取箱子物品、告示牌文字、旗帜图案或自定义头颅主人等方块实体数据。
- 默认创建上限为 **5,000 个 cube**，不是 5,000 个源方块；源方块处理上限另行设置。预览最多显示 2,048 个粗略实例，不等于完整模型或真实纹理预览。
- Java Block/Item 模型常见坐标范围为 `-16` 到 `32`。每格 1 单位时约为 48 格跨度；每格 16 单位时约为 3 格，不能把 48 格建议套用到所有比例。
- Minecraft JAR/ZIP 中的原版 PNG 仅作预览，不会在保存模型时自动另存。合并生成的自定义贴图需手动导出。
- 后台结构解析需要 Worker 与 DecompressionStream。最终 cube 创建和编辑仍会占用主线程及显存，超大建筑应缩小选区或分批导入。

安装包说明记录的实机环境为 Blockbench 5.2.2 与 Animated Java 1.11.0；尚未验证游戏内导出和动画播放。各版本文件、平台要求及更新说明请在本页“版本”中核对。
