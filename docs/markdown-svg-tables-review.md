# 正文 SVG 与表格图片兼容交付记录

2026-11-14。本轮基于 main `8c0b5be`，功能提交 `c1d2d3e`，开发分支 `feat/markdown-svg-tables`，可回滚标签 `baseline/markdown-svg-tables-20261114`。用户明确确认后，已合并、推送并发布官网与 Admin；没有保存、覆盖或重发任何真实作品及文档。

## 已实现

官网作品正文、文档正文和各自的 Admin 编辑／发布预览共用安全图片解析。Markdown 表格单元格现在可以使用 `<img src="图片地址" alt="说明" width="40" height="40">`，支持标准 Markdown 图片及静态 SVG 文件。尺寸在两端一致，表格图片不会变成轮播；手机表格保留横向滚动。原有普通图片轮播、文档左右图文容器和三语回退保留。

作品及文档的正文上传、拖入和文件粘贴支持静态 SVG，每张 ≤1 MiB；PNG、JPEG、WebP 维持每张 ≤10 MiB。图片仍先进入私有库，明确发布后才公开。SVG 上传验证保持原始字节与 SHA-256，不栅格化、不覆盖原文件。公共上传组件也允许已校验 SVG 作为封面候选，封面不会自动追加正文。

先粘贴含本机相对路径的正文，再批量上传配图时，系统按原文件名匹配并只替换图片目标地址，保留表格、宽高与说明。重复引用同一路径可绑定同一文件，远程 URL、代码与转义示例不改写；不同相对目录使用同名文件时明确拒绝并提示改名。没有匹配目标的图片保持原先光标插入行为。作品上传暂停期间删除了对应占位时，续传完成不会复活已删图片。

## 使用方法

1. 打开作品的“正文与预览 → 详情”，或文档的 Markdown 正文，将 `v1.1/发布页正文.md` 的内容粘贴进去。
2. 一次选中正文引用的 23 个 SVG 图标，将文件拖入正文，或用“上传图片／上传正文图片”选择。文件名保持原样；系统会将 `../rules/images/icons/...svg` 自动换为私有图片引用，原来的 40×40 表格排版不变。
3. 查看右侧官网效果预览。作品需要“保存草稿 → 发布预览 → 确认发布”；文档图片会自动保存草稿，再将文章设为待发布，通过“预览文档发布”确认差异。

浏览器不能直接读取正文中的 D 盘路径。先粘贴文字、再上传配图即可完成匹配，不必手动获取图片网址。此次不会代用户覆盖 Fimel Card 现有已发布正文。

## 安全与发布链路

不启用任意 HTML 或 `rehype-raw`。只将完整的 img 标签转换为图片节点，保留 src、alt、title 和有界数字尺寸；不传播事件、样式、脚本或 iframe。图片 URL 继续限制为 HTTP／HTTPS，私有资源协议只在对应的后台预览解析。文档的 HTML 图片源加入所有权分析、私有路径拒绝、图片准备和公开地址投影，避免只在编辑器显示、发布后漏图。

SVG 使用 lockfile 锁定的 `@xmldom/xmldom 0.9.12` 严格解析 XML，任何解析错误均拒绝；DTD、实体声明、外部样式处理指令提前拒绝，并限制字节数、节点数和深度。静态标签／属性白名单允许源文件使用的内部 use 引用、渐变、图案、阴影及颜色变量，拒绝脚本、事件、foreignObject、动画、外部链接、外部 CSS 和危险命名空间。作品分片上传在完整验证前不写入 verified 区，文档上传在验证前不写入图片对象。私有 SVG 响应额外使用 sandbox CSP，并保留 Admin 原有策略。

解析依赖与错误处理接口以 [xmldom 官方说明](https://github.com/xmldom/xmldom)及安装版本类型定义为准。`npm audit` 检查中新增 XML 依赖没有报告漏洞；当前仓库仍有原有工具链依赖告警，本轮没有进行无关的工具链升级。
