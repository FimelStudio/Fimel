# 更新日志

## 1.0.0 · 2026-10-12

- 首次在 Fimel 发布单文件 Windows x64 版本。
- 提供多目录内容索引、搜索、归属与图标显示、收藏和标签。
- 提供空间树图、分类占用与目录钻取，新增目录自动索引并分析。
- 提供经过预览确认的重命名、校验复制与移动、目录备份恢复及回收。
- 支持 PCL2、PCL CE、HMCL 打开与版本脚本关联。
- 中文和英文界面、深浅主题立即切换并保存。
- 原创图标、项目许可与第三方许可原文嵌入单个 EXE。

详细开发与验证记录见 [源码文档](https://github.com/Ylong4004/Minecraft-Explorer/tree/main/docs)。
