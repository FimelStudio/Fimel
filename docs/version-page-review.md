## 设计与现状核对

这是保留品牌的资源详情页调整，参考 Modrinth 版本列表的信息层级。沿用官网黑曜石／浅色背景、青色强调、Geist 与品牌像素字、2px 小圆角和 Lucide；不引入组件库或新动画。设计差异 3、动效 1、信息密度 6，优化集中在版本列表与明确的下载操作。路由、页签参数、导航、访问和下载事件保持。

现状：顶部下载按钮被版本选择卡片取代；版本页先显示旧手写 1.4.0，再追加结构化 1.6.1。发布只改变下载地址／版本／粗略大小，未同步更新日期与版本平台。线上 v1.6.1 文件 SHA-256 已与公开目录核对；包内 JS 版本为 1.6.1。GitHub README 仍为 1.4.0，因此本轮文案以已上传安装包中的 about.md、changelog.json 及源码标注为准，不把旧 README 当作新版本文档。
