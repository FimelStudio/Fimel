## 测试中发现并修复的问题

- Admin 与官网 Vite 缓存共用会造成优化依赖失效；为 Admin 分离缓存并预优化哈希线程依赖，避免首次选择大文件时页面重载丢失编辑。
- 初次作品库请求返回前可新建，返回值会覆盖新编辑；已禁用加载期间的新建/导入/导出，增加人为阻塞响应的浏览器回归。
- 批量图片回调持有旧状态会丢失前一张；使用当前回调，真实双图片上传确认均保留。
- Multipart 完成接口重复请求提前返回时未消费请求体；调整读取顺序，真实幂等完成通过。
- 本地 Miniflare 大对象复制后空闲连接复用会重置后续测试连接；运行时测试使用独立连接，1 GiB 完整验证通过。此测试传输设置不作为生产保证。
- 异常 Markdown URL 及损坏公开 JSON 的嵌套字段可导致渲染报错；已增加安全解析和浏览器回归。
- 最终定向官网回归在多任务并行时有一次 30 秒整项超时；trace 显示页面和导航均正常，单独复验通过，没有隐藏失败或扩大测试超时。
