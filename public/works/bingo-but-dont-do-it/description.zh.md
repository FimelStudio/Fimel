# Bingo But Don't Do It

将「不要做挑战」融入 Bingo 对局：完成目标的同时，也要避免触犯自己队伍的限制条件。

## 对局机制

- 队伍共享生命。
- 对抗词条与特殊事件。
- 可选语音关键词玩法。

## 游玩环境

目前发布版本面向 **Minecraft Java 1.21.11 / Fabric**。

请先在「版本」页核对 Fabric Loader、Fabric API 及可选依赖，再下载模组。语音关键词玩法需要额外安装 Simple Voice Chat。

## 下载与反馈

页面的下载按钮会优先查找 GitHub 最新正式发布版，获取失败时提供本站保存的 1.21.11 v1.0 JAR。
